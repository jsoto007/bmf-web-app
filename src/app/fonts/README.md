Self-hosted variable fonts (latin subset, weights 400–600), downloaded from
Google Fonts and served through `next/font/local` so builds never depend on
fonts.googleapis.com. Both are licensed under the SIL Open Font License 1.1.

- `CormorantGaramond.woff2` — Cormorant Garamond, headings
- `Lora.woff2` — Lora, body
